Core Features
⚔️
Slayer Progression
4 mob types — Zombie, Spider, Skeleton, Creeper — each with 5 independent levels. Kill mobs, earn XP, and track your progress per type.
📋
Slayer Tasks
Level-scaled kill tasks assigned per type. Kill goals grow with your level — from 15 kills at level 1 up to 350 at max. Completion rewards bonus XP.
🔥
Combo Streak
Kill mobs rapidly to build a combo streak worth up to 2× XP. Every kill within 10s of the last adds +10% to your multiplier — then it resets.
🏆
GUI & Leaderboards
Interactive inventory GUI with a main menu, per-type detail screens, and leaderboards backed by player-head icons. View your rank overall or per slayer type.
Slayer Types
Fully Configurable
Four Mob Types
Each slayer type tracks XP, kill count, level, and active task independently. Configure display names, kill thresholds, XP per kill, and boss XP rewards per type in config.yml — no restart needed with /slayadmin reload.

Progression
📈
XP & Leveling
Earn XP per kill that accumulates toward your next level. Thresholds are cumulative — 20, 70, 170, 370, 870 kills to reach each level.
⚡
Combo Multiplier
Each rapid kill adds +10% XP to your multiplier, capped at 2.0×. Miss the 10-second window and your streak resets to 1.
🎯
Task Rewards
Complete a task to earn 100 bonus XP (configurable). One active task per type — a new task auto-scales to your current level.
Server Owner Tools
🛠️
Admin Commands
Full admin suite: setlevel, addxp, reset, and reload. Manage any online player's slayer progression directly from in-game or console. /slayadmin
⚙️
Config Reference
Configure max level, combo timeout, XP multiplier, kill thresholds, and XP values per mob type. All values hot-reloadable without restarting your server.
