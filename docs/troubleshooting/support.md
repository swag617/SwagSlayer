# 🆘 Support

Need help with SwagSlayer? Here's how to get it.

## Before Asking for Help

1. **Check the FAQ** — [FAQ](faq.md) covers the most common questions
2. **Read the relevant docs page** — the feature you're having trouble with likely has a dedicated page
3. **Check the console** — most issues produce a log message with the root cause
4. **Try `/slayadmin reload`** — config issues often resolve with a reload

## Discord

Join the Discord server for real-time help:

[discord.gg/z5XZvPQUbG](https://discord.gg/z5XZvPQUbG)

Post in the appropriate channel with:
* Your server's Minecraft version
* Your Java version (`java -version`)
* The exact command or action that caused the issue
* Any relevant console output (errors, warnings)

## GitHub Issues

For confirmed bugs or feature requests, open an issue on GitHub:

[github.com/swag617/SwagSlayer/issues](https://github.com/swag617/SwagSlayer/issues)

When reporting a bug, include:
* **Minecraft version** (e.g., Paper 1.21.1)
* **Java version** (e.g., Java 21)
* **SwagSlayer version** (from plugin.yml or `/plugins`)
* **Steps to reproduce** — exactly what you did
* **Expected behavior** — what you expected to happen
* **Actual behavior** — what actually happened
* **Console output** — full stack trace if applicable
