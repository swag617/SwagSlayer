# SwagSlayer <small>v1.0.0</small>

> A custom mob-slayer progression system for Minecraft — track kills, level up per mob type, earn combo XP, and complete slayer tasks.

<span style="background:rgba(255,255,255,0.15);border:1px solid rgba(255,255,255,0.3);border-radius:20px;padding:4px 12px;font-size:13px;font-weight:600;margin-right:6px;">Paper 1.21+</span><span style="background:rgba(255,255,255,0.15);border:1px solid rgba(255,255,255,0.3);border-radius:20px;padding:4px 12px;font-size:13px;font-weight:600;margin-right:6px;">Java 17</span>

- ⚔️ 4 slayer types — Zombie, Spider, Skeleton, Creeper
- 📈 5 levels per type with configurable XP thresholds
- 🔥 Combo streak system — up to 2× XP for rapid kills
- 📋 Level-scaled slayer tasks with bonus XP rewards
- 🏆 Per-type and overall leaderboards with player-head GUI
